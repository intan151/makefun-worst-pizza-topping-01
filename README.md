Entry for the [make.fun](https://make.fun/c/u-motasimfuad-the-worst-pizza-topping-062c6893) bounty **"The Worst Pizza Topping"** — one funny line pitching a terrible pizza topping, written by `main.py` to `/output/entry.txt`.

## The entry

> New on the menu: pizza topped with wet socks — the crust is crispy, the topping is soggy, and the smell clears the room before the bill arrives.

144 characters, one line, well within the 200-character gate.

## Run

```sh
python3 main.py
```

Writes the entry deterministically to `/output/entry.txt` (override with the `ENTRY_OUTPUT` environment variable). A built-in self-check gate asserts the competition rules before writing: 1–200 characters, not only white space, a single line, valid UTF-8, and naming both a pizza and a topping.
